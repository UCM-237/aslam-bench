# Agentes DRL (.pt)

Copia aquí los pesos del actor que quieras evaluar (no se suben a Git: ver `.gitignore`).
Son los ficheros `actor_stage{S}_episode{N}.pt` que guarda `drl_active_slam` de
c3-aslamdrl-platform en `data/models/drl_active_slam/<sesión>/`. Solo hace falta el
`actor_*`; `critic_*`, `target_*`, los `.pkl` y el replay buffer no se usan.
